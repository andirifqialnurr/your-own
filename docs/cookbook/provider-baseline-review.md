## 3. Boundaries to preserve if directions are accepted

- **Database ownership:** Nest owns domain reads/writes, validation and transactions. The controlled migrator owns application DDL; runtime roles do not get schema creation, blanket provider-schema access or automatic `BYPASSRLS`. Provider-owned Auth/Storage schemas remain provider-owned. Any exceptional read needed for revocation requires a narrow reviewed adapter, not a generic `auth` schema grant.
- **Sessions:** web/admin stores hold only their own realm's opaque session digest/metadata and protected credential references. Approve encryption keys outside the DB backup, rotation/revocation and expiry before storing refresh tokens. Host-only Secure/HttpOnly cookies plus explicit CSRF/Origin checks; no broad parent-domain admin cookie. Staff authority is rechecked by Nest, not inferred from normal login.
- **Mobile:** account-required V1 remains; no guest mode. `shared_preferences` remains **appearance-only** (`your_own.appearance.v1`), never credentials. Review the actual auth SDK persistence adapter, OS-backed secret storage, encrypted local database/keys, pending-write retention and account-switch teardown before auth/record functionality.
- **Private storage:** uploads/downloads and worker reads follow current authorization; object bytes are not atomically committed with SQL. Use durable status/retry and denial-first deletion. Metadata visibility, signed grants and public/cache paths need negative tests.
- **Environments:** local/CI synthetic only; staging/production separate projects or equivalent independently isolated DB/issuer/storage/keys, with distinct permissions, callbacks/origins and push/email destinations. Current staging/production entry points stay fail-closed. No real data copied to local or CI.
- **Later infrastructure:** persistent Nest API and worker when actually needed; separate later Next.js apps. Queue/Redis, sockets, push, hosted CI and rendering engines are not automatically adopted with this bundle. ApexCharts remains held. No self-hosted full Supabase stack, unneeded Docker services or provider CLI is installed for this review.
